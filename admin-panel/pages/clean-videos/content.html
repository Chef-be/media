Nettoyer les vidéos mortes
Cet outil analyse votre base de données, exécute une tâche cron, détecte les vidéos YouTube, Dailymotion et Vimeo supprimées, puis les retire de votre base.

Ce processus peut prendre un certain temps. Vous pourrez constater les changements sur votre site après quelques minutes.
