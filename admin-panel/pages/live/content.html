Configuration de l’API Agora
Pour commencer à utiliser cette fonctionnalité, vous devez créer un compte sur Agora.

Utilisé pour stocker les flux vidéo si le stockage du streaming en direct est activé.
config->amazone_s3_2 == '1') ? 'checked': '';?>>
Nom de votre bucket Amazon S3.
Votre clé Amazon issue de vos identifiants AWS.
Votre secret Amazon issu de vos identifiants AWS.

Avant d’activer Amazon S3, assurez-vous d’avoir envoyé tout le dossier "upload/" vers votre bucket.

Avant de désactiver Amazon S3, assurez-vous d’avoir téléchargé tout le dossier "upload/" sur votre serveur.

Nous recommandons d’envoyer le dossier et les fichiers via S3cmd.

Si votre site est encore tout neuf, vous pouvez ignorer l’étape d’envoi, mais veillez à cliquer sur `Tester la connexion`.
