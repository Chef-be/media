Notre API vous permet de récupérer des informations depuis notre site via des requêtes GET et prend en charge les paramètres suivants :

Nom Signification Valeurs Description Obligatoire
type Type de requête. Avec get_channel_info, vous pouvez récupérer les données d’un utilisateur. Ce paramètre définit le type de la requête.

Comment commencer ?
  1. Créez une application de développement.

  2. Une fois l’application créée, vous recevrez un APP_ID et un APP_SECRET.

  3. Pour démarrer le processus OAuth, utilisez le lien {{CONFIG site_url}}/oauth?app_id={YOUR_APP_ID}

  4. Quand l’utilisateur final clique sur ce lien, il est redirigé vers la page d’autorisation.

  5. Une fois l’application autorisée par l’utilisateur final, il est redirigé vers votre nom de domaine avec le paramètre GET code, par exemple : http://yourdomain/?code=XXX
